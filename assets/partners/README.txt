PARTNER LOGOS
=============
The "Our Partners in Success" grid shows each partner's logo in grey and in full
colour on hover. If a logo file is missing, the card shows the partner's name
with a small icon instead — nothing breaks.

How to add / replace a logo
- PNG (transparent or white background), about 500 px wide, file name exactly as above.
- Use the official logo you are allowed to publish (partner permission where required).
